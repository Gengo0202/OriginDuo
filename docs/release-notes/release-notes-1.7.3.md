# 1.7.3

## 功能添加

- **组件页**：底栏新增「组件」，列出全部可设置的组件，点进去就是它们的尺寸与颜色。原来的九宫格入口已移除。

## 功能修复

- **胶囊右格的图标偏右**：闪电和 Wi-Fi 弧放进右格时会有一半露在轮廓外，电量数字却是贴着内边缘的。现在两者都以内边缘对齐。

## 功能变更

- **胶囊结构移到快捷编辑**：胶囊长度和左右两格的位置，从「组件外观 → 外观」移到首页的快捷编辑区，就在圆环/胶囊两个样式图块下面。点一行打开设置，不再把五个滑杆铺在页面上。
- **底栏图标**：首页改为房子，组件页用原来的滑块图标，关于页不变。

---

**安装**：覆盖安装即可，设置全部保留。
