## 新增

- **设置改成在图标上直接调**。首页把三合一图标放大画出来，点图标上的部位就能改对应的组件，开关、尺寸与颜色都在同一个弹窗里，长按也能打开。
- **每一处都可以排优先级**。图标的上、中、下各有一张列表，可以放多个组件并调整顺序：排在上面的那一项当前画不出来时（没有 Wi-Fi、没有在充电），由下一项顶上。
- **胶囊样式**。三合一图标除圆环外多了一种形状：外壳轮廓本身就是电量条，左侧显示时间，右侧显示一项读数，上下两排点穿过轮廓。
- **时钟可以单独调**。胶囊左侧的时间有自己的字号与字重。
- **两张卡可以分开显示**。卡一、卡二的信号点各自作为独立组件，能放进圆环的任意一处。
- **充电闪电可调大小**（60%–160%，默认 100%），圆环与胶囊都生效。
- **底栏**。设置页改为底部导航，取代此前的顶部标签栏。三种材质可选：贴合式、悬浮胶囊、液态玻璃；按钮内容可选只显示图标、只显示文字，或两者都显示。
- **下拉菜单改为柔光玻璃**。浮出的选单带折射与边缘高光。

## 改进

- **检查更新改为弹窗显示**。发现新版本后会弹出对话框，列出完整更新说明与安装包大小，可直接下载。
- **不再影响其他应用**。此前模块在状态栏上额外挂了一个窗口，导致某些应用的弹窗接收不到点击（例如 LSPosed 的授权提示）。现在字形直接画进系统自己的电池图标。
- **环外读数在空间不足时按优先级让位**。状态栏右侧位置不够时（例如弹出超级岛），依次隐藏网络类型标签、功率与温度，信号点保留到最后。
- **设置项的说明文字统一**。每个滑杆只写默认值与可调范围，开关与下拉不再附解释性文字。
- **环外组件的预览**。开关关着也照常显示该组件的样式，只有它确实无法显示时才提示。
- **顶栏改为渐变模糊**。底层轻模糊、上层重模糊，后者自上而下淡出。
- **顶栏的模糊随滚动切换**。页面在顶部时顶栏近乎透明，向下滚动时逐渐变厚变实。
- **右上角的重启按钮改为柔光玻璃圆盘**，玻璃随滚动淡入。
- **底栏的切换动画**。切换页面时底栏同时进行位移、透明度与缩放。
- **检查更新在国内网络可用**。此前常因网络拦截 GitHub 而失败，现在先经镜像站访问。

## 说明

- **升级后外观不变**。新增项默认都不改变当前显示，此前放置好的组件会从旧格式迁移过来。全新安装时各处的优先级列表为空，需自行添加组件。
- **胶囊左侧的时间跟随系统**：12 或 24 小时制取决于系统设置。
- **卡一 / 卡二仅对圆环生效**：胶囊样式下信号点仍由「显示移动信号点」统一控制。
