## 充电时环内显示电量

以前充电时环内显示什么，取决于你把组件放在了哪一格 —— 想看电量得先把它排进中间。

现在多一个开关：**组件外观 → 电量数字 → 充电时环内显示电量**。打开后，充电时中间直接显示电量百分比，**拔线自动恢复**你原来排的内容。

它不改你的布局，只是充电期间的临时显示。所以拔线后不会出现「我原来放的东西不见了」。

限定**环形样式** —— 胶囊和矩形没有单一的「中间」可借用。

## 连 Wi-Fi 时隐藏网络类型

**组件外观 → 网络类型 → 连 Wi-Fi 时隐藏网络类型**。

打开后，Wi-Fi 已连接时 `5G` 这类标签自动让位；断开 Wi-Fi 或切回流量时自动恢复。

三种样式都生效。标签说的是蜂窝网的状态，连着 Wi-Fi 时这个信息不看你也在，而它和 Wi-Fi 弧挤在同一段空间里。

## 修复：胶囊左右两格不再互相挤压

以前两格是**按内容宽度比例分配**内腔：左格放的时间长一点，右格的电量就窄一点，反之亦然。这也是为什么你调一格的位置，另一格会跟着动。

现在两格是**独立的组件**，各自贴住自己那一侧：

| | 宽度由谁决定 | 从哪里开始画 |
| --- | --- | --- |
| 左格 | **它自己的字号** | 内腔左边缘，向右长 |
| 右格 | **它自己的字号** | 内腔右边缘，向左长 |

**左格换内容，右格的位置和大小完全不动。** 两者只在真正撞上时才会各自收缩。

## 新增：Wi-Fi 弧尺寸

**组件外观 → Wi-Fi 弧 → Wi-Fi 弧尺寸**，默认 100%，可调 60–160%。

以前弧的粗细只能靠描边滑杆调，但那会连带把外框也加粗。现在尺寸是独立的一项，在各自样式的可用空间内放大，不会越过缺口。

## 新增：胶囊长度

**组件外观 → 外观 → 胶囊长度**，默认 0，可调 -30 到 +60。

加长的是**两端圆角之间的直线段** —— 圆角半径和高度都不变，所以胶囊变宽而不变胖。

## 修复：上下开口的高亮框不再横贯整个胶囊

在「组件排序」里按住上下两格的组件时，高亮框原来会从胶囊一头拉到另一头。它用的是**点击判定区**（整个胶囊 146.5 单位宽），而那里实际只有四个点、40 单位宽。

现在框贴合那排点，并且跨在轮廓线上（点是骑在轮廓线上的）。

## 变更：充电闪电不再是开关

以前「充电时显示闪电」是一个开关，和组件排序是两套互相矛盾的答案。

现在**完全由组件排序决定**：把闪电放进哪一格就画在哪一格，没放就由系统自己画。充电一定会有闪电，区别只是谁画的。

## 变更：Wi-Fi 弧默认粗细 12 → 8

只影响**新安装**。已经存过值的不会变。
