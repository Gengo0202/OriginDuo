# 1.7.2

## 胶囊左格可以放任意组件（时间不再是固定的 · #44 #47）

以前胶囊左格**固定画时间**。现在它是第四个可编辑的格子，和上、中、下一样在「组件排序 → 左部」里安排。

能放：网络类型、电量数字、Wi-Fi 弧、充电闪电、时间。列表里的顺序就是优先级 —— 第一个有内容可画的胜出，画不出来时自动退到下一个，所以格子不会空着。

状态栏的时间只在胶囊**真的画了时间**时才隐藏。选成 Wi-Fi 的话，状态栏照常有时间，不会出现「没时间了」。

## 胶囊左右两格的位置可分别调节（#49）

每一格都有**水平和垂直**两个滑杆，四向独立：

| 设置位置 | 项 |
| --- | --- |
| 组件外观 → 电量数字 / 网络类型 / Wi-Fi 弧 … | 左格水平位置、左格垂直位置 |
| 同上（右格的那一项） | 右格水平位置、右格垂直位置 |

**两格互不影响** —— 调一格的位置，另一格不会跟着动。

## 修复：胶囊左右两格不再互相挤压

以前两格是**按内容宽度比例分配**内腔：左格放的时间长一点，右格的电量就窄一点，反之亦然。

现在两格是**独立的组件**，各自贴住自己那一侧：

| | 宽度由谁决定 | 从哪里开始画 |
| --- | --- | --- |
| 左格 | **它自己的字号** | 内腔左边缘，向右长 |
| 右格 | **它自己的字号** | 内腔右边缘，向左长 |

**左格换内容，右格的位置和大小完全不动。**

## 充电时环内显示电量（#34）

**组件外观 → 电量数字 → 充电时环内显示电量**（默认关）。

打开后，充电时环的中间直接显示电量百分比，**拔线自动恢复**你原来排的内容。它不改你的布局，只是充电期间的临时显示。

限定**环形样式** —— 胶囊和矩形没有单一的「中间」可借用。

## 连 Wi-Fi 时隐藏网络类型（#48）

**组件外观 → 网络类型 → 连 Wi-Fi 时隐藏网络类型**（默认关）。

Wi-Fi 已连接时 `5G` 这类标签自动让位；断开 Wi-Fi 或切回流量时自动恢复。三种样式都生效。

## 新增：Wi-Fi 弧尺寸

**组件外观 → Wi-Fi 弧 → Wi-Fi 弧尺寸**，默认 100%，可调 60–160%。

以前弧的大小只能靠描边滑杆调，但那会**连带把外框也加粗**。现在尺寸是独立的一项，在各自样式的可用空间内放大，不会越过缺口。

## 新增：胶囊长度

**组件外观 → 外观 → 胶囊长度**，默认 0，可调 -30 到 +60。

加长的是**两端圆角之间的直线段** —— 圆角半径和高度都不变，所以胶囊变宽而不变胖。

## 修复：胶囊内字号拉不到顶

以前胶囊里字号拉到 44 就觉得小，再往上滑杆没有反应 —— 内腔是按固定比例分槽的，槽宽先触顶了。

现在胶囊的电量/时间/类型上限提到 **50**，是格子真正能承住的最大值。

## 修复：设置里的预览和状态栏不一致

预览曾经不跟随设置变化、也不跟随主题色。现在预览与状态栏用同一套绘制路径，你在预览里看到的就是加到状态栏上的样子。

## 修复：上下开口的高亮框不再横贯整个胶囊

在「组件排序」里按住上下两格的组件时，高亮框原来会从胶囊一头拉到另一头 —— 它用的是**点击判定区**（整个胶囊 146.5 单位宽），而那里实际只有四个点、40 单位宽。

现在框贴合那排点，并且跨在轮廓线上（点是骑在轮廓线上的）。

## 变更：充电闪电不再是开关（#50）

以前「充电时显示闪电」是一个开关，和组件排序是两套互相矛盾的答案。

现在**完全由组件排序决定**：把闪电放进哪一格就画在哪一格，没放就由系统自己画。充电一定会有闪电，区别只是谁画的。
