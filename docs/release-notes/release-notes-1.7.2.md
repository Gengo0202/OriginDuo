# 1.7.2

## 功能添加

- **胶囊左格可放任意组件**：以前固定画时间，现在和上、中、下一样在「组件排序 → 左部」里安排，可放网络类型、电量、Wi-Fi 弧、充电闪电、时间。列表顺序即优先级，画不出时自动退到下一个。状态栏时钟只在胶囊真的画时间时才隐藏。（#44 #47）
- **胶囊左右两格位置可分别调节**：每格各有水平和垂直两个滑杆，四向独立，两格互不影响。（#49）
- **充电时环内显示电量**：组件外观 → 电量数字，充电时中间显示百分比，拔线恢复原内容。仅环形样式。（#34）
- **连 Wi-Fi 时隐藏网络类型**：Wi-Fi 已连接时标签让位，断开或切流量后恢复。三种样式都生效。（#48）
- **Wi-Fi 弧尺寸**：组件外观 → Wi-Fi 弧，默认 100%，可调 60–160%。与描边滑杆独立，放大不会连带加粗外框。
- **胶囊长度**：组件外观 → 外观，默认 0，可调 -30 到 +60。加长两端圆角之间的直线段，圆角与高度不变。
- **隐藏桌面图标**：只关掉桌面入口，LSPosed 里仍可打开设置。（#38）
- **温度仅充电时显示**：开启后温度随功率一起出现和消失。（#45）

## 功能修复

- **胶囊左右两格不再互相挤压**：以前按内容宽度比例分配内腔，一格变宽另一格就变窄。现在两格是独立组件，各自按自己字号定宽，左格贴左边缘向右长、右格贴右边缘向左长。
- **胶囊内字号可以拉到顶**：上限从 44 提到 50，不再是滑杆到底也没反应的死区。
- **设置里的预览与状态栏一致**：预览改用与状态栏相同的绘制路径，跟随设置与主题色变化。
- **上下开口的高亮框不再横贯整个胶囊**：以前用的是点击判定区（整个胶囊宽），现在贴合那排点并跨在轮廓线上。
- **胶囊右格的位移范围**：原来与左格共用一套，大半行程无效，现在各自独立。
- **Wi-Fi 位置下拉**：胶囊样式下不再把「左部」显示成「下部」。
- **隐藏桌面图标开关的对齐**：从信息卡片里移出，独立成卡，与同页其他开关一致。

## 功能变更

- **充电闪电不再是开关**：完全由组件排序决定，放进哪格就画在哪格，没放则由系统绘制。充电一定会有闪电，区别只是谁画的。（#50）
- **日志降噪**：诊断信息收进调试日志开关，不再每帧打 info log。（#40）
- **Wi-Fi 弧默认粗细** 12 → 8。只影响新安装，已存过值的不会变。
