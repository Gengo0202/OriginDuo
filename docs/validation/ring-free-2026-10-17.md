## 行为

- 上、中、下均可放 Wi-Fi、移动信号/双卡、电量数字、充电闪电、网络类型或时间，也可留空。
  同一个组件只占一个槽位；移动已有组件交换槽位，新组件只替换目标内容。
- `ring_slots=-1` 使用原自动规则。首次绘制编辑或在编辑器选择自由布局时，将当前预览中的占用关系
  转为明确槽位。常规页没有场景选择，首次转换使用正常、有 Wi-Fi 的固定样本。
- 自由布局保持槽位稳定：无 Wi-Fi 或未充电时对应槽位暂时留空；其余部件保持原位。
  充电闪电独立于数字开关。Wi-Fi、数字、闪电开关保留，关闭后保留位置，重开恢复。
- 移动信号的环内/环外选项独立保存；选择环外保留环内预留槽位，切回时复用。
  环外堆叠仍受移动信号总开关控制，关闭堆叠时使用原生信号。
- 未由圆环或模块环外读数接管的内容交还系统；延迟隐藏回调重新读取当前所有权。
  锁屏屏蔽表只撤销本模块此前添加的项目，配置和充电岛状态改变时都刷新。
- 原生电量数字及充电提示遵循系统电池样式；样本中的样式 3 显示外侧百分比但不显示外侧闪电，
  不强制制造系统原先没有的组合。关闭模块后由系统完整接管。
- 自由圆环时间使用独立字号/字重与现有分钟更新器，移出后恢复原生时钟。
  矩形和胶囊保留各自布局；切换样式保留自由圆环的槽位。

## 设备验收与边界

当前 `adb devices` 无连接设备。桌面 Canvas 使用 Java2D Android 替身；断言不等同于 Android 字体、
GPU 或 Compose 手势实测。原生电池子视图测试使用简化 meter，不覆盖各 ROM 的完整电池样式实现。
本轮保留常规页，未发布版本或更新 GitHub Issue 状态。

1. 首次在充电/无 Wi-Fi 预览编辑下槽，核对未编辑的上下组件与转换前相同；关闭应用重开，位置保持。
2. 三槽逐一放置组件、交换及清空，分别切换充电/断网/双卡状态，观察占用提示与实际内容一致。
3. 关闭 Wi-Fi/数字/闪电，切换样式再切回，从组件弹窗重新开启；核对预留位置和原生图标归还。
4. 移动信号环内/环外及原生/堆叠切换，不改其他槽位；切回环内仍在原位置。
5. 任意槽位放时间，调整字号和字重，等待跳分钟，移出后核对系统时钟恢复。
6. 桌面、锁屏、控制中心及充电岛出现/收回中，核对未接管 Wi-Fi 与信号及时恢复，系统自己的屏蔽项保留。
7. 系统电池样式 0/1/2/3 分别核对数字和充电提示，模块关闭后恢复完整系统样式。
8. 320dp 宽、低高度、大字体和 TalkBack 下核对位置菜单、全部部件、滚动弹窗及关闭按钮。
