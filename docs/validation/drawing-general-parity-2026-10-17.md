# 绘制页承接常规页：第一阶段

此文件及其 manifest 为自由圆环之前的历史快照。当前源码及 APK 请按
[自由三槽验证记录](ring-free-2026-10-17.md)及其 manifest 核对。

目标：绘制页成为主要配置入口。常规页暂时保留；常规页与绘制部件弹窗复用同一份 `ContentControls.kt`，以后删除页面时不必重写设置逻辑。

## 已落地

- 绘制页顶部提供总开关和圆环/矩形/胶囊的可视化样式选择。
- 图标内部继续使用真实 renderer/zone transform 处理点击与长按。
- 环外网络类型、信号与功率/温度提供可点击内容预览；关闭时仍可打开设置。
- 「全部部件」提供整体外观、Wi-Fi、移动信号、电量、充电、网络类型、功率/温度入口，胶囊额外显示时间入口。隐藏部件不依赖当前区域是否能放置来编辑。
- 部件弹窗合并显示开关、位置、尺寸、字重和相关颜色。整体缩放、描边与底轨归整体外观；性能读数缩放与字重归功率/温度。
- 弹窗保留实时预览及场景切换；低高度或大字体下预览随内容滚动，避免挤掉设置视口。选择列表也可滚动，关闭按钮固定保留。
- 主编辑器提供跟随系统/浅色/深色背景。颜色调节弹窗展示对应状态的图标，并随色板修改立即更新。
- 文字区域入口与选择行提供标准 click/long-click、选中及禁用语义。图形区域继续通过文字入口提供等价的可访问操作。
- 颜色恢复沿用原确认弹窗，确认之前不写配置。

## 常规页 14 项映射

| 设置 | 绘制入口 |
| --- | --- |
| 总开关 | 顶部，或整体外观 |
| 三合一样式 | 顶部缩略图，或整体外观 |
| Wi-Fi | 全部部件 → Wi-Fi，或相应区域长按 |
| 移动信号 | 全部部件 → 移动信号 |
| 双卡 | 移动信号；原双卡部件入口同样归此组 |
| 电量数字 | 电量 |
| 信号位置 | 移动信号 |
| 堆叠信号 | 移动信号 |
| 仅上网卡 | 移动信号 |
| 充电闪电 | 充电 |
| 网络类型关闭/环内/环外 | 网络类型 |
| 电量数字居中 | 电量，依赖圆环、Wi-Fi 和电量数字 |
| 功率 | 功率与温度 |
| 温度 | 功率与温度 |

数据仍通过原 `SettingsRepository` setters 保存与同步到 SystemUI。常规页的顺序、存储索引及启用依赖保持原有含义；部分行现在多了依赖提示。

## 验证

自动验证入口：

```powershell
.\tests\capsule.ps1
.\tests\capsule-zones.ps1
.\tests\drawing-zones.ps1
.\tests\issue-regressions.ps1
. .\scripts\env.ps1
gradle :app:assembleDebug :app:assembleRelease --offline --no-daemon --console=plain
```

上述脚本验证渲染、区域求解和既有回归。`capsule.ps1` 的样式顺序检查已迁移到共享内容控件。它们不执行 Compose 手势，也不证明真实弹窗布局。

本轮结果：四个脚本通过（胶囊 78、胶囊区域 92、绘制区域 1,110、issue 回归 74 条执行断言，另有源码接线检查）；
最终 Debug/Release 构建成功（1m 16s）。独立代码复核确认 14 项功能等价；复核发现的列表滚动、低高度视口、
可访问动作及样本说明问题已补齐。UI 截图和真机手势仍待验证。

其他 agent 的 UI 验收清单：

1. 从绘制页开启模块、依次选择三种样式；切回常规页核对持久化结果，重启应用后再次核对。
2. 关闭 Wi-Fi/移动信号/电量/闪电后，从全部部件重新打开；不可因为部件已隐藏而失去入口。
3. 每种样式下检查网络类型三态、信号两种位置；进入环外堆叠，切换双卡与仅上网卡，核对依赖提示及预览。
4. 功率和温度四种组合；在普通/充电场景间切换，检查只有充电场景显示示例功率。更改尺寸及字重，检查保存结果。
5. 调整整体缩放、描边、底轨透明度，以及每个部件的尺寸/字重；切到尺寸页逐项核对值。
6. 低电量、危险、充电三种角色色分别切深浅背景调色，预览随之更新；恢复颜色先取消，再确认，检查写入时机。
7. 圆环和矩形的空区域、胶囊固定时间区、充电覆盖和无 Wi-Fi：保持原有选择/清空/长按行为。
8. 320dp 宽、横屏低高度、字体放大至 150%：滚动选择列表与 Mobile/整体外观弹窗直到末项，确认开关/滑杆/关闭按钮均可达。
9. TalkBack/键盘可通过区域文字行打开选择、选择组件，并通过长按动作进入设置；禁用和选中状态可以被识别。
10. 反复 picker → 部件 → 颜色/重置 → 关闭，检查没有叠加弹窗或点击穿透。切换预览背景/场景不应写实际系统状态。

## 验证边界与后续

目前没有连接设备，本轮 UI 未做屏幕截图、真实手势或 SystemUI 实测。功率/温度采用合成内容样本，尚未与运行期文字尺寸算法共用实现；卡片高度有限时会限制样本文字尺寸。环外独立样本也不是整条状态栏最终间距的模拟。

下一阶段优先建立完整组合预览并共用运行期尺寸/布局规则，再补充配置撤销与恢复能力；完成设备验收及功能等价核对后，再决定移除常规页。
