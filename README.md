# HyperDuo

把状态栏里的 **Wi-Fi、移动信号、电量** 合并成一个仿 iPhone「Duo」风格的三合一图标。

![状态栏效果](docs/images/statusbar.png)

HyperDuo 是一个 LSPosed 模块，只作用于系统界面（`com.android.systemui`）。开启后，状态栏
右上角原本分开的 Wi-Fi 图标、信号格与电池图标会被替换成一个整体字形：

- 外圈是**电池环**，缺口在下方，按电量点亮；
- 环里是 **Wi-Fi 弧线**，弧数跟随真实信号强度；
- 底部是**移动信号点**，四个点表示移动网络信号强度；
- 环内是**电量数字**，充电时变成闪电（快充为琥珀色闪电）。

所有元素都能单独开关，尺寸、颜色也可以按自己的状态栏习惯微调，改完**立即生效**，无需重启。

关掉其中任何一项，对应的**系统原生图标**都会回到状态栏原本的位置——关掉 Wi-Fi 弧，
原生 Wi-Fi 图标回到系统默认位置；关掉移动信号点，原生信号格回来；关掉充电闪电，充电时就由
系统原生的闪电显示在电池图标旁。也就是说每个开关都是「用三合一的画法」与「用系统原本的画法」
之间的切换，而不是简单地少画一笔。

也可以选择**胶囊**：轮廓本身表示电量，左侧显示时间，右侧放一项读数，上下两排点表示移动信号。
时间有独立的字号与字重，和电量数字分别调整。

**字形画在电池图标自己的 drawable 槽里。** 三合一不再是另开一个窗口盖在状态栏上，而是写进 MIUI
电池图标本来就有的那个 drawable 槽。画布、bounds、裁剪和硬件层全部由系统提供，模块只是往槽里
放一个自己画的 drawable。因此没有「窗口高度不够、超出部分被裁掉」这回事，也没有窗口需要在下拉
通知栏、最近任务、启动动画、全屏应用或充电动画岛接管时让位——字形就是电池图标的内容，系统怎么
排它，它就怎么显示。

这样做还顺手解决了「某个应用遮挡了权限请求界面」的问题：旧版把字形画在一个系统级覆盖层窗口里，
平台于是把它当成可能劫持触摸的窗口，落在它下面的触摸被打上「被遮挡」标记，带防护的应用（例如
**LSPosed 的权限请求界面**）检测到后拒绝响应。现在模块不再创建任何窗口，也就不存在这个判定。

环外还可以再挂几个读数：**网络类型标签**、**充电功率**、**电池温度**。功率取的是电池自身电流
的幅值 × 电压，也就是真正充进电池的功率，会随电量升高逐渐变小——刻意不取充电器协商的最大档位
（电流的正负号各家平台不一致，本机充电时答负数，所以只取幅值）；不足 10W 保留一位小数，没接
充电器时这一段直接不显示（而不是显示 0W）。温度是电池自己的属性，不接充电器同样显示。

**状态栏右侧空间不够时会按优先级让位。** 位置被超级岛占去时，依次隐藏网络类型标签、功率与温度，
信号点保留到最后——不是把所有内容一起缩小到看不清。

## 效果预览

![效果预览](docs/images/states.png)

从左到右：充电、快充、正常、无 Wi-Fi（显示网络类型）、省电、危险。这套预览也内置在设置
界面，会跟着你的设置实时变化。

## 安装

### 前置条件

| 项目 | 要求 |
| --- | --- |
| 系统 | HyperOS / MIUI（已在 HyperOS 4 上完整验证） |
| Android | 10 及以上（API 29+） |
| 框架 | 支持 libxposed **API 102** 的 LSPosed，例如 LSPosed 2.2.0-it（7890） |

### 步骤

1. 从 [Releases](https://github.com/yixing233/HyperDuo/releases) 下载最新的 `HyperDuo-*.apk`
   并安装。
   > 如果 Releases 里还没有可用安装包，可以按 [开发文档](docs/DEVELOPMENT.md) 自行构建。
   > 新版包名是 `io.github.yixing233.hyperduo`（1.3 及更早是 `com.hyperduo.trio`）。包名变了
   > 就是另一个应用，**无法覆盖升级**：请先卸载旧版（设置会一起清掉），再装新版。
2. 打开 **LSPosed 管理器** → 模块 → 启用 **HyperDuo**。
3. 在模块的作用域里勾选 **系统界面（`com.android.systemui`）**。
4. 重启系统界面让模块生效：可以在 LSPosed 里点「重启作用域」，可以重启手机，也可以在设置界面顶栏
   点右侧的**重启按钮**（需要 root 授权）。

重启系统界面也可以直接用命令：

```sh
adb shell "su -c 'killall com.android.systemui'"
```

### 打开设置

安装后桌面会出现 **HyperDuo** 图标，点开即可；也可以在 LSPosed 管理器里点击模块进入。

设置界面「关于」页会显示模块是否已经在系统界面里跑起来：

| 状态 | 含义 |
| --- | --- |
| **已激活** | 模块已获得框架服务，设置修改会立即生效。 |
| **未激活** | 请确认模块已在 LSPosed 中启用，并且勾选了作用域。 |

## 设置说明

![设置界面](docs/images/settings.png)

设置界面只有两页：**首页**与**关于**。首页是编辑的地方，关于页是信息与更新。

### 首页

首页把三合一图标放大画在顶部，下面按五张卡片组织。

#### 总开关

| 设置项 | 说明 | 默认 |
| --- | --- | --- |
| 启用三合一图标 | 总开关。关闭后恢复系统原本的电池与信号图标。 | 开 |

关掉总开关时预览仍然照你选的样式画——否则这一页就无从下手——并会有一行字说明状态栏不会跟着显示。

#### 快捷编辑

点图标上的部位直接改它。图标被分成**上部 / 中部 / 下部**三块热区，点哪块就编辑哪块，
长按也能打开。

区域行显示的是当前预览实际画出的内容，不会把空白处标成某个组件。点按打开组件列表，
挑一个换上去或清空；长按直接调整它的尺寸与颜色。

**预览状态**（正常 / 充电 / 快充 / 低电量 / 危险 / 无 Wi-Fi）用来把预览切到平时不容易出现的
状态：充电闪电要有充电器、低电量与危险色要有低电量。没有这一排，这几项在这一页上就根本没有
可按的地方。

所选组件如果被当前状态暂时覆盖，页面会说明原因和查看方式：例如正常状态下选择闪电，会提示
切到充电预览；无 Wi-Fi 时选择弧线，会提示切到正常预览。

#### 组件排序

图标的上、中、下每一处各有一张**优先级列表**，可以放多个组件并调整顺序。排在上面的那一项
当前画不出来时（没有 Wi-Fi、没有在充电），由下一项顶上，那一片区域不会空着。

可放的组件：电量数字、充电闪电、Wi-Fi 弧、移动信号点、卡一信号点、卡二信号点、网络类型、时钟。

- 卡一、卡二各自是**独立组件**，各画一行四点，可以放进任意一处，两个开关互不影响。
  一行四点始终是**一张卡**的读数：卡二在没有第二张卡（或读不到电平）时整行不点亮，
  而不是画成满格。这两项**只在圆环样式下生效**。
- 移动信号的「环内 / 环外」是独立切换，切到环外会记住原位置。
- 组件设置里的位置选项可以把内容**交还系统**：Wi-Fi、信号、时间会回到系统原位，电量数字与
  充电提示遵循系统电池样式。未被接管的组件不会因为设置开关还开着而继续被隐藏。

#### 环外组件

信号不一定要画在环里。把移动信号的位置从**环内**改成**环外**，它就挪到电池图标旁边——
和原生信号格、网络类型同一个位置，圆内只剩 Wi-Fi 与电量。

此时打开「**堆叠信号**」，模块自己接管那一处读数：**四条高度递增的圆头柱**表示一张卡，
**下方一排圆点**表示另一张卡，一眼看出两张卡各自几格。只有一张卡时只画柱。关闭它则把移动信号
整体**交还系统**，由原生信号格显示——这也是环外模式的默认状态。

双卡时还可以打开「**仅显示上网卡**」，只画当前承载数据的那张卡。

这张卡片里还有环外读数的样式：**网络类型**（关闭 / 环内 / 环外）、**充电功率**、
**电池温度**、**堆叠信号大小**与**间距**。

#### 组件外观

按组件列出它的尺寸与颜色：

| 组件 | 可调 |
| --- | --- |
| 电池环 | 粗细（4–16，默认 14）、底纹浓度（0–255，默认 56）、状态颜色 |
| Wi-Fi 弧 | 粗细（3–16，默认 12） |
| 电量数字 | 字号（16–44，默认 36）、字重（100–900，默认 700） |
| 充电闪电 | 大小（60%–160%，默认 100%） |
| 网络类型 | 环内字号（16–44，默认 32）、环外字号（8–26dp，默认 14）、字重、5GA 中 A 的比例（50%–100%，默认 65）、环外左右边距（0–16dp） |
| 移动信号点 | 环外字号（6–20dp，默认 15）、间距（0–16dp） |
| 读数组 | 整体尺寸（60%–150%，默认 100%）、字重（100–900，默认 700） |
| 时间 | 字号（16–44）、字重（100–900） |
| 图标整体 | 整体尺寸（60%–100%，默认 100%） |

几处说明：

- **环外网络类型字号按 dp 算**（8–26dp），会随屏幕密度自动换算，与圆环的设计空间各自独立刻度。
  这也是为什么它的上界比环内字号更高。
- **环外信号大小**同样按 dp 算：15dp 就是与图标同高，且不随状态栏那一行变化（下拉控制中心时
  那一行会从 88 像素变成 134 像素，读数不会跟着长大）。
- **环外信号间距**是**会占位**的边距：调大时读数远离电池、原生图标同时让出同样宽度，所以读数
  不会压到别的图标上。
- **5GA 中的 A**：网络类型以 A 结尾时（如 5GA），末尾的 A 相对主字号的百分比，底边与主字对齐，
  环内与环外同时生效。100% 即不再缩小。
- **图标整体尺寸**按系统给电池图标预留的那块区域（约 28dp × 20dp）的百分比算。100% 已经等于
  系统允许的最大值，所以只能往下缩：预留区域是系统画的、模块改不动它，往大调只会画到视野外面。

**状态颜色**的优先级是：**危险电量 → 低电量 / 省电 → 充电 → 前景色**。低电量阈值默认 20%
（可调 5%–50%）。三种状态颜色都可以**分别**为深色背景和浅色背景设置一套，点按条目就能选择。
环的底纹和未激活的信号点会跟随状态栏本身的前景色，所以换主题、开深色模式都能自动适配。
末尾的「**恢复默认**」会把三种状态颜色恢复为出厂预设，点击后先弹确认对话框——这一步会一次性
覆盖六种自定义颜色（三种状态 × 深/浅背景）。

### 关于

显示模块版本、系统版本、Xposed 框架、设备型号、作用域与 Android 版本，并提供**检查更新**。

检查更新是**手动**触发的：只有点按「检查更新」这一行时才会访问网络，模块不会在后台自动联网。
发现新版本后会弹出对话框，列出完整更新说明与安装包大小，可直接在应用内下载并调起系统安装器。
更新卡片底部固定有**查看仓库**，点按后在浏览器打开 GitHub 仓库主页（与「打开发布页面」互补：
一个看源码与说明，一个看 Release），只在点按时才打开浏览器。

页面底部的**调试日志**开关会把详细过程写入 LSPosed 日志，排查问题时开启。

## 常见问题

**改完设置需要重启系统界面吗？**

不需要。模块通过框架的远程配置通道实时接收变更，改完立刻重绘。

如果确实需要重启（例如刚装上模块、或系统界面状态异常），设置界面顶栏右侧就有重启按钮；它也
需要 root 授权，和上面的命令效果相同。

**状态栏完全没有变化？**

依次确认：模块已在 LSPosed 中启用 → 作用域勾选了「系统界面」→ 已经重启过系统界面。三者都
满足后仍然无效，请检查手机上是否还有别的状态栏类模块在同时改动同一区域。

**状态栏图标还是原样，但设置里显示「已激活」？**

框架连接正常说明模块进程在跑，问题通常出在作用域——没有勾选 `com.android.systemui` 时模块
不会被注入到系统界面里。

**升级后设置全没了、LSPosed 里还多出一个同名模块？**

包名换了（`com.hyperduo.trio` → `io.github.yixing233.hyperduo`），Android 会当成两个不同的应用：
旧版不会自动升级、旧设置不会迁移、LSPosed 里两条并列。卸载旧的 `com.hyperduo.trio` 与它那条
作用域记录，只留新版即可。

**「关了 Wi-Fi 弧还在」？**

不会。Wi-Fi 的**有无**有实时采样兜底，关掉 Wi-Fi 后弧线会消失。但 Wi-Fi 的**信号等级**依赖
系统界面内部的资源名解析，个别固件改走别的绑定路径时，弧线可能只显示为不点亮（不会崩溃）。

**切换「显示移动信号点」后没有马上变化？**

移动信号点只在信号等级变化时刷新。这是已知限制：系统界面在移动视图淡出后仍报告「可见」，
模块无法从中判断开关状态，所以需要等下一次信号变化（或重启系统界面）才会完全同步。

**字号调大后字形被裁切了？**

系统给电池图标预留的区域是固定的（28dp × 20dp），几何参数只改变绘制内容，不会改变预留尺寸。
极端值下字形可能超出可用范围，调小一点即可。

**支持哪些机型和系统？**

目前只在 **小米 14 · HyperOS 4 · Android 17（API 37）** 上做过完整验证。HyperOS / MIUI 的其他
机型与版本理论可用，但状态栏内部实现不同时，对应功能会自动跳过并写下日志，不会崩溃。

**检查更新提示「作者尚未发布任何正式版本」？**

说明 GitHub 仓库里还没有 Release，不是出错。等作者发布第一个带 APK 的 Release 后，这里就会
显示版本比对了。

**检查更新失败？**

GitHub 在部分网络环境（尤其是国内）会被代理拦截，表现为请求超时或直接断开。模块会先经镜像站
访问、失败再回原地址；两边都不通时，可以点**查看仓库**在浏览器里手动查看。

**下载完更新，点「安装」没有反应？**

首次从应用内安装需要系统授权。模块检测到没有权限时会自动打开「安装未知应用」设置页，允许
之后再回来点一次「安装」即可。

## 排查问题

设置里打开「调试日志」后，可以这样观察模块输出：

```powershell
adb logcat -v time -s LSPosedFramework:* | Select-String HyperDuo
```

- 日志的 tag 是 **`LSPosedFramework`**（由框架代打），**不是** `HyperDuo`。
- 启动时会打印一行 `HyperDuo installed, hooks=9`；某个功能没生效时会打印
  `skip <id>: method not found`，说明当前系统的实现和模块的预期不一致。
