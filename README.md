# HyperDuo

把状态栏里的 **Wi-Fi、移动信号、电量** 合并成一个仿 iPhone「Duo」风格的三合一图标。

![状态栏效果](docs/images/statusbar.png)

HyperDuo 是一个 LSPosed 模块，只作用于系统界面（`com.android.systemui`）。开启后，状态栏
右上角原本分开的 Wi-Fi 图标、信号格与电池图标会被替换成一个整体字形：

- 外圈是**电池环**，缺口在下方，按电量点亮；
- 环里是 **Wi-Fi 弧线**，弧数跟随真实信号强度；
- 底部是**移动信号点**，四个点表示移动网络信号强度；
- 环内是**电量数字**，充电时变成闪电（快充为琥珀色闪电）。

所有元素都能单独开关，尺寸、颜色也可以按自己的状态栏习惯微调，改完**立即生效**，无需重启。

关掉其中任何一项，对应的**系统原生图标**都会回到状态栏原本的位置——关掉「显示 Wi-Fi 弧」，
原生 Wi-Fi 图标回到系统默认位置；关掉「显示移动信号点」，原生信号格回来；关掉「充电时显示
闪电」，充电时就由系统原生的闪电显示在电池图标旁。也就是说每个开关都是「用三合一的画法」与
「用系统原本的画法」之间的切换，而不是简单地少画一笔。

如果更喜欢把电量数字放大到环心、让 Wi-Fi 弧缩到顶部缺口，打开「**电量数字居中**」即可。
开启后数字始终优先占据圆心：充电时改用**顶部缺口里的小闪电**（此时不再画 Wi-Fi 弧，充电状态
一眼可见），环内的网络类型也会让位到缺口。

也可以在「**三合一样式**」里把排布换成**矩形**：左右两列信号点夹住中间的内容，顶部是 Wi-Fi 弧
（或网络类型，充电时是闪电），中部偏下是放大的电量数字，底部是一条横贯左右的电量条。矩形样式
沿用同一套字体、颜色与尺寸设置，只是「环线粗细」这一行会改叫「**电量条粗细**」，对应底部电量条
的厚度。矩形样式没有圆环，所以「电量数字居中」在矩形下会变灰并提示先切回圆环。

第三种是**胶囊**：轮廓本身表示电量，左侧显示时间，右侧按「充电闪电 → Wi-Fi → 电量数字 →
网络类型」决定当前读数，上下两排点表示移动信号。胶囊会按自身比例申请更宽的图标区域，系统原生
时钟在此样式下隐藏，切回圆环/矩形或关闭模块后恢复。时间有独立的字号与字重，和电量数字分别调整。

**字形画在电池图标自己的 drawable 槽里。** 三合一不再是另开一个窗口盖在状态栏上，而是写进 MIUI
电池图标本来就有的那个 drawable 槽（`mTintBgDrawable`）：画布、bounds、裁剪和硬件层全部由系统
提供，模块只是往槽里放一个自己画的 drawable。因此没有「窗口高度不够、超出部分被裁掉」这回事，
也没有窗口需要在下拉通知栏、最近任务、启动动画、全屏应用或充电动画岛接管时让位——字形就是电池
图标的内容，系统怎么排它，它就怎么显示。

这样做还顺手解决了 issue #28 与 #33：那两条报的是「某个应用遮挡了权限请求界面」，成因是旧版把
字形画在一个系统级覆盖层窗口里，平台于是把它当成可能劫持触摸的窗口，落在它下面的触摸被打上
「被遮挡」标记，带防护的应用（例如 **LSPosed 的权限请求界面**）检测到后拒绝响应。现在模块不再
创建任何窗口，也就不存在这个判定。**这一条从 1.6.13 起生效，不需要你手动关 LSPosed 的「点按劫持
缓解」。**

双卡手机还可以打开「**双卡信号**」：改成上下两排信号点，**上排是卡一、下排是卡二**，一眼看清两张
卡各自几格。圆环样式下两排点正好落在圆环的两个缺口里，所以此时圆环的缺口会保持打开：上排把
12 点钟的缺口**张到与底部开口等宽**，让上下两排对称、点也不会和环的圆头糊在一起。单卡手机、
或只有一张卡能读到电平时，仍然只画一排——那一排始终表示**当前上网卡**。

圆环顶部只有一个缺口，所以占用它的东西是有**先后顺序**的：

| 顺序 | 占用者 | 说明 |
|---|---|---|
| 1 | 双卡信号 | 两排点（需双卡且都读到电平） |
| 2 | Wi-Fi 弧 | 缩进缺口（需开启「电量数字居中」） |
| 3 | 环内网络类型 | 如 5G（需「网络类型」选**环内**） |
| — | 都不满足 | 圆环**闭合**成整圆 |

唯一能插到双卡前面的是**环内充电闪电**（需同时开启「充电时显示闪电」）：它占缺口时，Wi-Fi 弧
整组不画，两排点也让位。把「充电时显示闪电」关掉后闪电交还系统原生图标，缺口就不再为它保留，
于是双卡／Wi-Fi／类型照常占用——这是「关闭闪电后顶部仍有信息」的原因。

信号不一定要画在环里。把「**信号位置**」从**环内**改成**环外**，移动信号就从圆环底部挪到
电池图标旁边——和原生信号格、网络类型同一个位置，圆内只剩 Wi-Fi 与电量。此时打开
「**堆叠信号**」，模块自己接管那一处读数：**四条高度递增的圆头柱**表示一张卡，**下方一排圆点**
表示另一张卡，一眼看出两张卡各自几格，而且柱子从矮到高，比两排点更紧凑。只有一张卡时只画柱。
关闭「堆叠信号」则把移动信号整体**交还系统**，由原生信号格显示——这也是环外模式的默认状态。
双卡时还可以再打开「**仅显示上网卡**」，只画当前承载数据的那张卡，另一张完全不画。

两个开关都**只在环外模式下生效**：环内的点阵、以及上面说的「双卡信号」两排点，都不受它们影响。

环外读数的大小可以单独调：**环外信号大小**是一行 dp，**15dp 就是它默认的样子**——正好和
状态栏图标一样高。需要放大或缩小时再动它，范围 6\~20dp，放宽和收紧都不会影响环内画法。
用的是 dp 而不是百分比：dp 会随屏幕密度自动换算，大小不参照状态栏那一行有多高，所以把控制
中心拉下来——那一行会从 88 像素变成 134 像素——读数也不会跟着长大。
这项还顺带修掉了一个尺寸异常：环外读数**有没有下方那排圆点**，此前会被当成两种不同的参照高度
（有圆点 209 单位、没有圆点 150 单位），于是同一行里单卡读数会比双卡读数高出一大截（约 1.39 倍）。
现在两种形状共用同一个参照框：圆点只是内容，不影响比例，同一行上下两种画法必定一样大。

电池图标旁边还能再挂两个读数（默认都关）：**充电功率**与**电池温度**。功率取的是电池自身
电流的幅值 × 电压，也就是真正充进电池的功率，会随电量升高逐渐变小——刻意不取充电器协商的最大
档位（电流的正负号各家平台不一致，本机充电时答负数，所以只取幅值）；
不足 10W 保留一位小数，没接充电器时这一段直接不显示（而不是显示 0W）。温度是电池自己的属性，
不接充电器同样显示。两项共用同一处位置，且一项占一行：只开一项就只显示那一项，两项都开则上下
两行显示——两项横着排会挤到旁边的原生图标。字号以**环外网络类型字号**为基准：
只开一项时与环外标签一样大，两项都开时按电池图标的高度自适应缩小，让两行合起来不高于一个图标；
空间实在太窄时会在基准字号的六成处封底，此时两行会略微高过图标一点，而不会缩到看不清。
这个基准之上还有**读数整体尺寸**可以把两项读数整体放大或缩小（60 – 150%）。

**充电超级岛出现时自动让位。** HyperOS 充电时弹出超级岛、把电池图标临时藏起来，此时三合一
字形跟着隐藏，Wi-Fi **交还给系统原生图标**，移动信号则按**环外读数**显示（即使你平时用的是
环内点阵）；岛收回后一切按你原来的设置恢复。图标行让出岛的空间时，环外读数也一起跟着右移。

## 效果预览

![效果预览](docs/images/states.png)

从左到右：充电、快充、正常、无 Wi-Fi（显示网络类型）、省电、危险。这套预览也内置在设置
界面顶部，会跟着你的设置实时变化；内置预览还多两格：「**环外类型**」显示环外标签的字号与
结尾 A 的比例（示例类型固定为 5GA），「**环外信号**」显示堆叠信号的形状、大小与它离电池的
间距（那两样都由系统状态栏绘制，预览是它们唯一能看到效果的地方，**环外信号大小**、**环外
信号间距**与 **5GA 中 A 的比例**这几项也正是照着这两格调的）。刚加的**充电功率**与**电池温度**
两项在预览里没有格子——八格一行已经排满——它们的开关效果只在状态栏上看得见。**字形整体**与
**两项读数整体**都可以单独缩放：「图标整体尺寸」缩的是整个三合一字形（只能往小缩，系统的预留
区域就那么大），「读数整体尺寸」缩的是两项读数（自适应字号之上的百分比，可大可小），
「读数字重」则调这两项读数文字的笔画粗细。这三项都在「尺寸」页。

## 安装

### 前置条件

| 项目 | 要求 |
| --- | --- |
| 系统 | HyperOS / MIUI（已在 HyperOS 4 上完整验证） |
| Android | 10 及以上（API 29+） |
| 框架 | 支持 libxposed **API 102** 的 LSPosed，例如 LSPosed 2.2.0-it（7890） |

### 步骤

1. 从 [Releases](https://github.com/yixing233/HyperDuo/releases) 下载最新的 `HyperDuo-*.apk`
   并安装。
   > 如果 Releases 里还没有可用安装包，可以按 [开发文档](docs/DEVELOPMENT.md) 自行构建。
   > 新版包名是 `io.github.yixing233.hyperduo`（1.3 及更早是 `com.hyperduo.trio`）。包名变了
   > 就是另一个应用，**无法覆盖升级**：请先卸载旧版（设置会一起清掉），再装新版。
2. 打开 **LSPosed 管理器** → 模块 → 启用 **HyperDuo**。
3. 在模块的作用域里勾选 **系统界面（`com.android.systemui`）**。
4. 重启系统界面让模块生效：可以在 LSPosed 里点「重启作用域」，可以重启手机，也可以在设置界面顶栏
   点右侧的**重启按钮**（需要 root 授权）。

重启系统界面也可以直接用命令：

```sh
adb shell "su -c 'killall com.android.systemui'"
```

### 打开设置

安装后桌面会出现 **HyperDuo** 图标，点开即可；也可以在 LSPosed 管理器里点击模块进入。

设置界面顶部的「关于」页会显示模块是否已经在系统界面里跑起来：

| 状态 | 含义 |
| --- | --- |
| **已激活** | 模块已获得框架服务，设置修改会立即生效。 |
| **未激活** | 请确认模块已在 LSPosed 中启用，并且勾选了作用域。 |

「关于」页同时显示模块版本、系统版本、Xposed 框架、设备型号、作用域与 Android 版本，并提供
**检查更新**：点按后会到 GitHub Releases 比对最新版本，有新版本时可以直接在应用内下载并调起
系统安装器。更新卡片底部固定有**查看仓库**，任何状态下都能点开 GitHub 仓库阅读源码与说明。
同一页底部还有「调试日志」开关。

设置界面按 **常规 / 绘制 / 尺寸 / 颜色 / 关于** 五个分页组织，顶部是跟着设置实时变化的
「效果预览」，顶栏右侧还有一个**重启系统界面**按钮。

### 绘制

上面那些开关都是**用名字**描述一个部件；这一页反过来，**把三合一按原样画大**，让你直接点你
想改的那一笔。图标被分成**上部 / 中部 / 下部**三块热区：

| 分页 | 圆环样式 | 矩形样式 |
| --- | --- | --- |
| 上部 | 12 点缺口：电量数字、充电闪电、双卡上排点，或「数字居中」后缩进缺口的 Wi-Fi 弧 | 顶部槽位：闪电、Wi-Fi 弧，或网络类型 |
| 中部 | 圆环内部：Wi-Fi 弧、居中放大的电量数字，或网络类型 | 放大的电量数字 |
| 下部 | 底部四个电平点 | 左右两列信号点，以及它们之间的电量条 |

胶囊对应「**左侧时间 / 右侧读数 / 边界信号**」三个区域。左侧时间是固定内容，点按或长按直接
调整时间字号与字重；右侧读数与边界信号可以选择组件或清空，时间与胶囊的电量轮廓保留。

**点一下**图标区域或下方的区域行，打开组件列表，挑一个换上去；选择「**空**」则清除该区域的
可选组件。清空会同时检查有无 Wi-Fi、充电与未充电状态，切换预览后也保持为空；圆环和电量条保留。
**长按**图标上已有的组件、下方区域行或菜单里的组件，直接调整它的尺寸与颜色；长按空白区域则
打开组件列表。区域行显示的是当前预览实际画出的内容，无 Wi-Fi 时不会把空白处标成 Wi-Fi 弧。

**预览状态**（正常 / 充电 / 快充 / 低电量 / 危险 / 无 Wi-Fi）用来把预览切到平时不容易出现的
状态：充电闪电要有充电器、双卡两排点要有两张卡都有电平、低电量与危险色要有低电量。没有这一排，
这几项在这一页上就根本没有可按的地方。

所选组件如果被当前状态暂时覆盖，页面会说明原因和查看方式：例如正常状态下选择闪电，会提示
切到充电预览；充电时选择其他组件，会提示闪电优先；无 Wi-Fi 时选择弧线，会提示切到正常预览。

总开关关掉时预览仍然照你选的样式画——否则这一页就无从下手——并会有一行字说明状态栏不会跟着显示。

对话框——这一步会一次性覆盖六种自定义颜色（三种状态 × 深/浅背景），确认后才写入。

## 常见问题

**改完设置需要重启系统界面吗？**

不需要。模块通过框架的远程配置通道实时接收变更，改完立刻重绘。

如果确实需要重启（例如刚装上模块、或系统界面状态异常），设置界面顶栏右侧就有重启按钮；它也
需要 root 授权，和上面的命令效果相同。

**状态栏完全没有变化？**

依次确认：模块已在 LSPosed 中启用 → 作用域勾选了「系统界面」→ 已经重启过系统界面。三者都
满足后仍然无效，请检查手机上是否还有别的状态栏类模块在同时改动同一区域。

**状态栏图标还是原样，但设置里显示「已激活」？**

框架连接正常说明模块进程在跑，问题通常出在作用域——没有勾选 `com.android.systemui` 时模块
不会被注入到系统界面里。

**升级后设置全没了、LSPosed 里还多出一个同名模块？**

包名换了（`com.hyperduo.trio` → `io.github.yixing233.hyperduo`），Android 会当成两个不同的应用：
旧版不会自动升级、旧设置不会迁移、LSPosed 里两条并列。卸载旧的 `com.hyperduo.trio` 与它那条
作用域记录，只留新版即可。

**「关了 Wi-Fi 弧还在」？**

不会。Wi-Fi 的**有无**有实时采样兜底，关掉 Wi-Fi 后弧线会消失。但 Wi-Fi 的**信号等级**依赖
系统界面内部的资源名解析，个别固件改走别的绑定路径时，弧线可能只显示为不点亮（不会崩溃）。

**切换「显示移动信号点」后没有马上变化？**

移动信号点只在信号等级变化时刷新。这是已知限制：系统界面在移动视图淡出后仍报告「可见」，
模块无法从中判断开关状态，所以需要等下一次信号变化（或重启系统界面）才会完全同步。

**打开「双卡信号」后还是只画一排点？**

两排点需要三个条件同时成立：手机确实是双卡、两张卡都读到了电平、并且**没有在画环内充电闪电**。
任何一条不满足就回退成单排（当前上网卡），这样比画一排空点更有信息量。如果插着两张卡却仍只有
一排，多半是其中一张卡没有信号或已停用——那一排就会按当前上网卡来画。

注意抑制它的**不是"在充电"而是"画闪电"**：如果「充电时显示闪电」是关的（闪电交还系统原生图标），
那么插着充电器时两排点照样会画出来。要让它给闪电让位，就把「充电时显示闪电」打开。

**圆环顶部有时候闭合、有时候显示别的东西？**

顶部缺口只有一个位置，按「双卡信号 → Wi-Fi 弧 → 环内网络类型」的先后占用，都不满足时圆环就闭合
成整圆（开启「电量数字居中」时数字在圆心，不占缺口）。所以「没有 Wi-Fi 信号」时看到闭合的圆环是
正常的，不是缺内容。详见上文「双卡信号」一节的顺序表。

**字号调大后字形被裁切了？**

系统给电池图标预留的区域是固定的（28dp × 20dp），几何参数只改变绘制内容，不会改变预留尺寸。
极端值下字形可能超出可用范围，调小一点即可。

**支持哪些机型和系统？**

目前只在 **小米 14 · HyperOS 4 · Android 17（API 37）** 上做过完整验证。HyperOS / MIUI 的其他
机型与版本理论可用，但状态栏内部实现不同时，对应功能会自动跳过并写下日志，不会崩溃。

**检查更新提示「作者尚未发布任何正式版本」？**

说明 GitHub 仓库里还没有 Release，不是出错。等作者发布第一个带 APK 的 Release 后，这里就会
显示版本比对了。想先看看模块到底做了什么，点更新卡片底部的**查看仓库**。

**下载完更新，点「安装」没有反应？**

首次从应用内安装需要系统授权。模块检测到没有权限时会自动打开「安装未知应用」设置页，允许
之后再回来点一次「安装」即可。

## 排查问题

设置里打开「调试日志」后，可以这样观察模块输出：

```powershell
adb logcat -v time -s LSPosedFramework:* | Select-String HyperDuo
```

- 日志的 tag 是 **`LSPosedFramework`**（由框架代打），**不是** `HyperDuo`。
- 启动时会打印一行 `HyperDuo installed, hooks=9`；某个功能没生效时会打印
  `skip <id>: method not found`，说明当前系统的实现和模块的预期不一致。
